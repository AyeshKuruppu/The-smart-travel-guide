# Smart Travel Guide 🌍✈️

A simple **Prolog-based Smart Travel Guide** that helps users find routes to destinations and discover nearby hotels and camping sites.

## ✨ Features

- Find travel routes
- Find nearby hotels
- Find camping sites
- Prolog-based knowledge base
- Simple logical reasoning
